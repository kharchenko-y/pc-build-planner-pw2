How a build comes together

  1. Create a buildName it and set a budget in euros, or leave it unlimited.
  2. Add partsChoose CPU, motherboard, RAM and the rest from the catalogue. Set quantities for drives and memory.
  3. Check the essentialsCPU socket and RAM generation are compared with the motherboard.
  4. Print or exportA report lists every build with its current total. Download it as CSV.

What the planner covers

Checked

  • CPU socket against the motherboard socket
  • RAM generation against the motherboard memory type
  • Total cost against the build budget

Not checked

  • BIOS support, cooling and physical clearance
  • Power supply capacity and other requirements

About the catalogue

  • Parts and prices are demonstration data
  • Totals always use the current catalogue price
