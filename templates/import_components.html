Import components

Add several catalogue parts from one CSV file. If any row is invalid, nothing is imported.

File requirements

  • UTF-8 CSV, up to 50 components and 32 KiB.
  • Use these headers in order: category,name,price_eur,socket,ram_type
  • Category names must match the catalogue. Socket and memory follow the same rules as the component form.
