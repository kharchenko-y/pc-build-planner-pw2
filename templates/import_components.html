Import components

Add several parts from one CSV file. If any row is invalid, nothing is imported.

File requirements

  • UTF-8 CSV, up to 50 parts and 32 KiB.
  • Header: category,name,price_eur,socket,ram_type,specs. The specs column is optional.
  • Categories use the catalogue names: CPU, Motherboard, RAM, GPU, Storage, PSU, Case. Separate key specifications with semicolons.
