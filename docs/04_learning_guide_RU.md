# Как объяснить PC Build Planner

## Создание сборки

1. HTML-форма отправляет `POST /builds/new` с названием, бюджетом и CSRF-токеном.
2. `create_build()` в `app.py` проверяет сессию, CSRF, название и сумму. `money_cents()` из `domain.py` превращает `800.25` в `80025`.
3. Запрос `INSERT INTO builds ... VALUES (?, ?, ?)` сохраняет ID владельца и данные. Значения передаются отдельно от текста запроса.
4. Ответ 303 отправляет браузер на `GET /builds/{id}`. F5 повторяет чтение, поэтому запись не дублируется.

## Связи между таблицами

- Один пользователь владеет несколькими сборками.
- Каждая сборка содержит несколько строк `build_items`. Каждая строка указывает на одну деталь в `components`.
- Один тип из `categories` группирует много деталей.
- `login_sessions` хранит отпечаток токена и срок действия. Эта таблица отвечает за вход.
- `ON DELETE CASCADE` удаляет строки состава вместе со сборкой. `ON DELETE RESTRICT` защищает деталь, пока она используется.

## Цена, поиск, совместимость

Каждая цена хранится в центах. Для каждой строки умножаем цену на количество. Итог на странице сборки считает Python, а список и отчёт используют SQL `SUM`. При смене цены в каталоге итог обновляется.

`lookup()` в `catalogue.py` соединяет `components` и `categories`. Поиск учитывает два поля. Обычная форма делает GET, а JavaScript вызывает GET для фрагмента таблицы и обновляет только результаты.

`compatibility()` сверяет сокет CPU и поколение RAM с данными материнской платы. AM5 + AM5 и DDR5 + DDR5 проходят. AM5 + LGA1700 выдаёт предупреждение. При отсутствии части появляется подсказка, какие данные нужны.

## Как объяснить безопасность

- При входе сервер выпускает новый случайный токен. В SQLite лежит его SHA-256-отпечаток, в подписанной cookie лежит токен. Запись действует два часа. При выходе запись удаляется.
- `owned_build()` ищет запись одновременно по ID сборки и ID пользователя. Администратор управляет каталогом и подчиняется тому же правилу владения сборками.
- Каждое изменение требует CSRF-токен. HTML выводит пользовательский текст через экранирование Jinja.
- Импорт CSV выполняет администратор. Файл читается в памяти с лимитом, данные проверяются и сохраняются одной транзакцией. Имя файла не используется как путь.
- `pcbuild_view` запоминает Cards или List на 30 дней и не участвует во входе.

## Попробуй объяснить самостоятельно

1. Откуда функция узнаёт владельца сборки и что покажет, если ID не совпал?
2. Что произойдёт с итогом при цене 7500 центов и количестве 2?
3. Почему нельзя удалить компонент, пока на него ссылается `build_items`?
4. Покажи, как добавить новый текст ошибки для неподходящего сокета. Найди соответствующую проверку в `domain.py`.
5. Покажи в сети браузера разницу между отправкой HTML-формы поиска без JavaScript и запросом Fetch.
